# Student Result Management System - C++ 🎓

A comprehensive C++ application developed to manage student academic records, built during pre-BSCS preparation to master fundamental programming and Object-Oriented Programming (OOP) concepts.

---

## 📌 Project Overview
This repository contains a full **Student Result Management System** along with topic-wise practice modules demonstrating core C++ concepts.

- **Main Application:** Handles student records, mark calculations, grade assignments (A, B, C, D, F), and formatted tabular display.
- **Future Target:** Building a strong C++ portfolio for **Global Korea Scholarship (GKS)** / Master's degree in South Korea 🇰🇷.
